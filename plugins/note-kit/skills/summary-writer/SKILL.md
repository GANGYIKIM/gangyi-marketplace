# Summary Writer

사람이 쓴 원본과 AI가 만든 요약을 분리해 보관하는 스킬이다. 요약에는 AI의 해석이나 추측이 섞일 수 있으므로, 원본과 다른 폴더에 두고 요약 안에서도 원문의 내용과 AI의 해석을 나눠 적는다. 그래야 나중에 요약만 보고도 어디까지 믿어도 되는지 알 수 있다.

## 핵심 원칙

- **요청이 곧 승인이다.** 요약을 파일로 만들어 달라는 요청을 받았으면 바로 만들어 저장한다. 먼저 확인받는 경우는 아래 "저장 위치"와 "이름이 겹칠 때"에 적힌 두 가지뿐이다.
- **원문 문장을 옮기지 않는다.** 모든 내용을 새로 풀어 쓴다. 원문을 다시 읽지 않아도 이해되게 하고, 웹 글의 저작권을 지키기 위해서다.
- **원문의 내용과 AI의 해석을 섞지 않는다.** 원문이 말하는 것은 "핵심 내용"에, 원문에 직접 없는 추론·배경·연결은 "AI 해석"에 쓴다.
- **한국어로 쓴다.** 원문 언어와 상관없이 한국어로 요약하고, 고유명사와 기술 용어는 원어를 괄호로 함께 적는다. 예: 서버 컴포넌트(Server Components)

## 진행 순서

- [ ] 1. 원본 읽기와 이름 정하기
- [ ] 2. 저장 위치 정하기
- [ ] 3. 기존 요약 찾기와 이름 겹침 확인
- [ ] 4. 요약 작성과 저장
- [ ] 5. 결과 알리기

### 1. 원본 읽기와 이름 정하기

- **원본이 파일이면** 그 파일을 읽는다. 형식별 읽는 방법은 [references/format.md](references/format.md)의 "형식별 읽기"를 따른다. docx, pptx, 영상처럼 읽을 수 없는 형식이면 요약하지 않고 "이 형식은 읽을 수 없으니 PDF나 텍스트로 바꿔 주세요"라고 알린 뒤 멈춘다. 요약 파일 이름은 원본 파일 이름에서 확장자만 바꾼 것이다. 접미사는 붙이지 않는다. 예: `clips/react19_출시.html` → `react19_출시.md`
- **원본이 대화에 붙여 넣은 글이면** 20자 안팎의 명확한 명사구로 제목을 정해 파일 이름으로 쓴다. 구어체 문장은 피하고, 공백은 하이픈으로 바꾼다.
- 원문이 웹에 있는 글이면 원문 주소를 찾는다. 찾는 방법은 [references/format.md](references/format.md)를 따른다.

### 2. 저장 위치 정하기

위에서부터 처음 해당하는 것을 따른다.

1. 사용자가 이번 요청에서 위치를 말했으면 그곳
2. 프로젝트의 CLAUDE.md에 요약 저장 위치 규칙이 있으면 그곳
3. `summaries/` 폴더가 이미 있으면 그곳
4. 위에 모두 해당하지 않으면 처음 만드는 것이다. 저장하기 전에 "기본 위치인 `summaries/`에 만들까요, 다른 위치를 지정하실래요?"라고 묻는다. 사용자가 `summaries/`가 아닌 위치를 고르면, 다음에 같은 질문을 받지 않도록 "이 위치를 CLAUDE.md에 규칙으로 남길까요?"라고 한 번 더 묻는다.

하위 폴더는 만들지 않고 저장 위치 바로 아래에 저장한다.

### 3. 기존 요약 찾기와 이름 겹침 확인

1. **원본 경로로 먼저 찾는다.** 저장 위치의 요약 파일들에서 `원본 파일` 줄이 이번 원본과 같은 파일을 찾는다. 있으면 파일 이름이 달라도 같은 원본의 요약이므로, 확인 없이 그 파일을 덮어쓴다. 요약은 원본에서 다시 만들 수 있으므로 버전을 남기지 않는다.
2. **없을 때만 이름 겹침을 확인한다.** 정한 이름의 파일이 이미 있으면 다른 원본의 요약이다. 덮어쓰기 전에 기존 요약의 원본 경로를 보여주고, 덮어쓸지 다른 이름으로 저장할지 고르게 한다. 다른 이름은 이렇게 제안한다.
   - 기존 요약의 원본과 형식(확장자)이 다르면 이름 뒤에 원본 형식을 붙인다. 예: `clips/react19.pdf` → `react19_pdf.md`
   - 형식이 같으면 원본의 상위 폴더 이름을 앞에 붙인다. 예: `notes/b/정리.md` → `b_정리.md`
   - 제안한 이름도 이미 있으면 둘 다 붙인다. 예: `b_정리_md.md`

### 4. 요약 작성과 저장

[references/format.md](references/format.md)의 형식과 길이 기준으로 요약을 쓰고 저장한다.

### 5. 결과 알리기

저장한 뒤에는 한 줄 요약과 저장 경로만 짧게 알린다. 요약 전문을 대화에 다시 붙이지 않는다.
