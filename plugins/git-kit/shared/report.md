# PR 보고서 코멘트

PR 첫 코멘트로 다는 보고서의 구조다. 표시, 섹션별 담당, 결정 부분 템플릿을 정한다.
pr-writer, decision-resolver가 읽는다. commit-writer는 읽지 않는다.

## 표시

| 표시 | 뜻 |
|---|---|
| `<!-- git-kit:report -->` | 보고서 코멘트. 코멘트 첫 줄 |
| `<!-- git-kit:decisions -->` … `<!-- /git-kit:decisions -->` | 결정 부분의 시작과 끝 |

- 보고서는 PR 코멘트 중 첫 줄이 `<!-- git-kit:report -->`인 것으로 찾는다.
- 섹션은 제목 글자가 아니라 표시로 찾는다.
- 표시에는 내용 이름만 넣고 스킬 이름은 넣지 않는다. 담당은 아래 표에서 정한다. 담당이 바뀌어도 이미 있는 PR은 고치지 않아도 된다.
- 표시에 버전을 붙이지 않는다. 형식이 바뀌면 그때부터 `v2`를 붙이고, 예전 형식을 읽는 법을 이 파일에 적는다.

## 섹션별 담당

| 부분 | 처음 만들기 | 그 뒤 고치기 |
|---|---|---|
| 결정 부분 (표시 안쪽) | pr-writer가 결정 기록으로 만든다 | decision-resolver만 |
| Decisions made, Please check (표시 바깥쪽) | pr-writer | pr-writer만 |

- pr-writer는 표시 안쪽을 한 글자도 바꾸지 않고 그대로 옮긴다.
- decision-resolver는 표시 바깥쪽을 바꾸지 않는다.
- 결정 부분이 있으면 바깥쪽이 비어도 보고서를 "남은 항목 없음"으로 바꾸지 않는다.
- 쌓인 PR의 머지 순서는 결정 부분에 쓰지 않는다. pr-writer가 Please check의 상태 항목으로 쓴다.

## 결정 부분 템플릿

### 결정이 남아 있을 때

```
<!-- git-kit:report -->
<!-- git-kit:decisions -->
> [!WARNING]
> 결정 대기. 머지 전 아래 Decisions needed의 결정 필요.
> 답하는 법: 항목마다 선택지 하나 체크. 선택지에 없는 답은 PR 코멘트로 작성. 이후 Claude에게 결정 반영 요청.

## Decisions needed
### D<번호>. <결정할 것>
- 결정: <고른 답> · 반영 커밋 [<해시 7자리>](<커밋 링크>)
- 미결정 이유: <이유, 개조식>
- 현재 임시값: <임시값>
- 의존: D<번호>가 <선택지>일 때만 필요
- 관련 위치:
  - [`<경로>:<줄>`](<고정 링크>) <역할>
- [ ] <선택지> (추천): <장단점, 개조식>
- [ ] <선택지>: <장단점, 개조식>
<!-- /git-kit:decisions -->

## Decisions made
…

## Please check
…
```

### 결정이 모두 끝났을 때

```
<!-- git-kit:report -->
<!-- git-kit:decisions -->
> [!NOTE]
> 결정 완료 (<날짜>).
> Draft 유지: <사람 판단 (<날짜>, <이유>)|자동 모드 (사람이 해제 필요)>

## Decisions resolved
### D<번호>. <결정할 것>
- 결정: <고른 답> · 반영 커밋 [<해시 7자리>](<커밋 링크>)
- [x] <선택지> (추천): <장단점, 개조식>
- [ ] <선택지>: <장단점, 개조식>
<!-- /git-kit:decisions -->

## Decisions made
…

## Please check
…
```

### 규칙

- `- 결정:` 줄은 결정됨, 반영됨, 필요 없음일 때만 쓴다.
  - 결정됨: `- 결정: <고른 답>`
  - 반영됨: `· 반영 커밋 …`을 붙인다. 여러 개면 쉼표로 잇는다.
  - 필요 없음: `- 결정: 필요 없음 (D<번호>가 <답>)`
  - 체크박스가 아닌 곳에서 답했으면 `· 답한 곳: <곳>`을 붙인다.
- 체크박스는 사람이 체크한 상태 그대로 둔다.
- 모든 D가 끝나면 WARNING을 NOTE로, `Decisions needed`를 `Decisions resolved`로 바꾼다. D 블록은 `- 결정:` 줄과 선택지만 남기고 나머지 줄(미결정 이유, 현재 임시값, 의존, 관련 위치)은 뺀다.
- `Draft 유지` 줄은 Draft를 유지했을 때만 쓴다. `(<이유>)`는 사람이 대화에서 이유를 말했을 때만 붙인다.
- D 블록의 줄 내용(미결정 이유, 현재 임시값, 의존, 관련 위치, 선택지, 기록에 선택지가 없을 때)은 pr-writer의 `references/decision-pending.md` 규칙을 따른다.
- Decisions made와 Please check는 pr-writer 규칙을 따른다.

## 표시가 깨졌을 때

- 결정 표시가 한쪽만 있거나 순서가 뒤집혔으면 두 스킬 모두 보고서를 고치지 않고 알린다.
- 결정 대기 PR인데 결정 표시가 없는 예전 보고서는 decision-resolver가 처음 고칠 때 `> [!WARNING]`부터 `## Decisions needed`의 마지막 D 블록까지를 표시로 감싼다. pr-writer는 이런 보고서를 만나면 결정 부분을 고치지 않고 그대로 옮긴다.
