# 커밋 타입

git-kit의 커밋 메시지, 브랜치 이름, PR 제목이 함께 쓰는 type과 이모지다.
commit-writer, pr-writer, decision-resolver가 읽는다.

| 이모지 | type | 쓰임 |
|---|---|---|
| ✨ | feat | 새 기능 추가 |
| 🐛 | fix | 버그 수정 |
| ♻️ | refactor | 동작 변화 없는 코드 구조 개선 |
| 🎨 | style | 로직 없는 포맷·코드 스타일 변경 (CSS 스타일 변경은 제외) |
| 📝 | docs | 문서 수정 |
| ✅ | test | 기존 코드의 테스트 추가·수정 |
| 🔧 | chore | 설정, 의존성, 빌드 같은 기타 작업 |

- **type 고르기**: 변경의 주된 목적에 맞는 type을 고른다. feat와 fix가 헷갈리면 fix를 쓴다.
- **이모지**: `:sparkles:` 같은 단축 코드가 아니라 이모지 문자를 그대로 쓴다. 터미널의 `git log`에서는 단축 코드가 이모지로 바뀌지 않기 때문이다.
- **🚧**: type이 아니다. 결정 대기 PR의 제목에서만 type 이모지 자리에 쓴다. 결정 대기가 끝나면 제목의 type에 맞는 이모지로 되돌린다.
