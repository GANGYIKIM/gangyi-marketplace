# 링크 안내

## 언제 읽는가

gh와 GitHub MCP가 모두 없을 때 읽는다. PR을 만들거나 갱신할 수 없으므로, push(확인 모드는 확인 후) 뒤 사람이 PR을 만들 수 있게 링크와 함께 제목, 본문, 보고서 코멘트를 복사할 수 있게 보여주고 끝낸다.

## 템플릿

SKILL.md "6. 마무리 안내"의 다른 템플릿 대신 아래를 쓴다. 템플릿 규칙은 SKILL.md의 "안내 언어와 형식"을 따른다.

````
PR 링크 안내 · <현재 브랜치> → <base 브랜치>
push: 커밋 <개수>개 (경고: <핵심 줄>)
Draft로 만들어 주세요 (<결정 대기 PR|자동 모드>)

아래 링크에서 PR을 만들어 주세요.
https://github.com/<저장소>/pull/new/<현재 브랜치>

제목:
<제목>

본문:
```
<본문>
```

보고서 코멘트 (PR을 만든 뒤 첫 코멘트로 붙여 주세요):
```
<보고서>
```
````

- "push" 줄은 이번에 push한 커밋이 있을 때만 쓴다. 괄호는 push는 됐지만 git이 경고나 오류를 출력했을 때만 쓴다.
- "Draft로 만들어 주세요" 줄은 Draft로 만들어야 하는 PR일 때만 쓴다. 결정 대기 PR이거나 자동 모드일 때다. 둘 다면 "결정 대기 PR"을 쓴다.
- "보고서 코멘트"는 보고할 내용이 있을 때만 쓴다.
- 쌓인 PR이면 머지 순서의 이 PR 번호를 모르므로 `이 PR`로 쓴다(`shared/report.md`의 "순서 만들기").
