# Next.js

| 설치된 버전의 명령, 설정, 린트, 폴더 규칙 | `node_modules/next/dist/docs/` (16.2 이상에 들어 있다. 뼈대가 만드는 `AGENTS.md`가 이 폴더를 가리킨다) |

## 뼈대

도구는 create-next-app이다.

## 조건

### Project

- **테스트 도구**: 뼈대의 가져오기 경로 별칭(`@/*`)을 테스트 도구가 읽을 수 있어야 한다.

### UI

- **컴포넌트의 서버 호출·저장 금지**: 막을 것에 서버 전용 모듈의 import와 서버 액션을 더한다.
- **접근성**: 프레임워크의 기본 린트 설정이 켜 둔 접근성 규칙만으로 충족이라고 보지 않는다.

## 확인 방법

| 조건 | 위반 예시가 꼭 담아야 하는 것 | 나와야 하는 것 |
|---|---|---|
| 접근성 | 프레임워크의 기본 린트 설정이 잡지 않는 위반 | 실패. 출력에 접근성 규칙의 이름 |
